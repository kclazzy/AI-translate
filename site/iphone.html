AI Translate для iPhone и iPad

Те же возможности, что на Android. iOS не позволяет рисовать поверх других приложений, поэтому переводите страницы в приложении или скриншоты через меню «Поделиться».

Открыть веб-приложение

Веб-приложение (без App Store)

  1. Откройте веб-приложение в Safari.
  2. Кнопка «Поделиться» → «На экран Домой».
  3. Запускайте с главного экрана: оно работает как обычное приложение и хранит настройки на устройстве.

Нативное приложение

Проект для Xcode лежит в apps/mobile/ios. Нужен Mac с Xcode и Apple ID:

pnpm install
pnpm --filter @ait/mobile ios   # соберёт веб-часть и откроет Xcode

GitHub Actions также собирает неподписанный .ipa — его можно подписать своим Apple ID через Sideloadly или AltStore.
