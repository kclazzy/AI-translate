AI Translate для компьютера

Расширение браузера переводит мангу прямо на сайте. Для лучшего качества на своей видеокарте добавьте локальный движок.

Скачать последнюю версию

1. Установить расширение

  1. Скачайте ai-translate-desktop-*.zip и распакуйте.
  2. Chrome / Edge / Brave / Opera: откройте chrome://extensions, включите «Режим разработчика», нажмите «Загрузить распакованное» и выберите папку extension-chrome.
  3. Firefox: about:debugging → «Этот Firefox» → «Загрузить временное дополнение» → файл extension-firefox/manifest.json.

2. Выбрать модель

В настройках расширения выберите модель, которая понимает изображения: локальную (Ollama, LM Studio) или облачную по ключу (Gemini, Claude, OpenAI, OpenRouter).

ollama pull qwen2.5vl:7b
# чтобы расширение могло обращаться к Ollama:
setx OLLAMA_ORIGINS "chrome-extension://*,moz-extension://*"

3. Локальный движок (по желанию)

Движок на Python ищет баблы, распознаёт текст и аккуратно убирает его на вашей видеокарте. Нужен Python 3.11+.

  1. Запустите engine\scripts\start-engine.bat. В окне появится адрес и код сопряжения.
  2. В настройках расширения выберите «Локальный движок» и вставьте код.
  3. Для RTX 50xx и японского OCR: engine\scripts\install-gpu-extras.bat (PyTorch CUDA 12.8 и manga-ocr).

Режим «Только локально» запрещает отправлять что-либо за пределы компьютера и локальной сети.
