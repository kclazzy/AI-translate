# Расширение AI Translate (Manifest V3)

Для Chrome, Edge, Brave, Opera (сборка `dist/`) и Firefox 128+ (сборка `dist-firefox/`).

## Сборка

```bash
pnpm install
pnpm --filter @ait/extension build
```

## Установка

- Chromium: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → `dist`.
- Firefox: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → `dist-firefox/manifest.json`.

## Как пользоваться

- Наведите на картинку — появится кнопка «Перевести».
- Popup: «Перевести страницу», «Перевести область», «Оригинал ⇄», автоперевод для сайта, язык, профиль, модель.
- Клавиши: `Alt+Shift+T` — перевести страницу, `Alt+Shift+A` — область, `Alt+Shift+O` — оригинал/перевод.
- Контекстное меню картинки: «Перевести изображение».
- На переведённой картинке: ⇄ оригинал, ◫ сравнение со слайдером, ✎ редактор, ⟳ перевести заново.

## Устройство

| Часть | Файл | Роль |
| --- | --- | --- |
| Content script | `src/content` | поиск `<img>`, CSS-фонов, `<canvas>`, ленивой загрузки; кнопка при наведении; оверлей в закрытом Shadow DOM; автоперевод; выделение области |
| Service worker | `src/background` | маршрутизация, загрузка картинок с Referer страницы, скриншоты, контекстное меню, бейдж |
| Offscreen | `src/offscreen` | конвейер, очередь, кэш, шрифты (в Firefox работает в фоновой странице) |
| Popup | `src/popup` | быстрые действия |
| Студия | `src/pages` | редактор, главы, глоссарий, настройки, история |

Если сайт не отдаёт картинку (защищённый canvas, blob, hotlink), расширение переводит то, что видно на экране.

Для Ollama задайте `OLLAMA_ORIGINS=chrome-extension://*,moz-extension://*`, для LM Studio включите CORS в настройках сервера.
