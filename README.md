# AI Translate

Переводчик манги, манхвы, вебтунов и комиксов. Находит текст на странице, убирает оригинал (японский, корейский, китайский и другие) и вписывает перевод в те же баблы. Работает с облачными моделями по вашему ключу или полностью локально на вашей видеокарте.

| Версия | Что это | Где взять |
| --- | --- | --- |
| Компьютер | Расширение для Chrome, Edge, Brave, Opera, Firefox + локальный движок на Python | `apps/extension`, `engine` — релиз `ai-translate-desktop-*.zip` |
| Android | Веб-приложение (PWA с «Поделиться») и проект Android (Capacitor) | `apps/mobile` — веб: GitHub Pages `/app/`, APK: GitHub Actions |
| iPhone / iPad | То же веб-приложение и проект Xcode | `apps/mobile/ios` — неподписанный `.ipa`: GitHub Actions |

Страницы установки для каждой версии: `site/` (публикуются на GitHub Pages).

## Как это работает

```
Страница с мангой ─► расширение (content script) ─► service worker ─► offscreen-документ
                                                                        │
              ┌─────────────── без движка ──────────────────────────────┤
              │  vision-модель находит и читает текст (Ollama, LM Studio,│
              │  Gemini, Claude, OpenAI…), очистка и вёрстка — на месте  │
              └─────────────── с движком ───────────────────────────────┘
                 движок на Python (GPU): поиск баблов → OCR (manga-ocr,
                 PaddleOCR или vision-модель) → перевод → очистка
                 (заливка / OpenCV / LaMa) → обратно в браузер
```

- **Общее ядро** `packages/core` (TypeScript): провайдеры моделей, промпты, проверка ответов, глоссарий, контекст серии, очистка изображения, вёрстка текста в бабл (перенос, подбор кегля, форма бабла, вертикальный текст), тайлинг длинных вебтунов, формат проекта, кэш.
- **Студия** `packages/studio` (React): редактор страницы, главы и проекты, глоссарий, настройки, история, приватность. Используется и в расширении, и в мобильном приложении.
- **Движок** `engine` (Python, FastAPI): классический детектор баблов без весов, OCR, перевод, OpenCV/LaMa, задачи с потоком событий (SSE), кэш на SQLite, защита: только localhost/LAN, токен сопряжения, CORS только для расширений и приложения.

## Быстрый старт (разработка)

Нужны Node.js 20+, pnpm 10+, Python 3.11+.

```bash
pnpm install
pnpm --filter @ait/core test           # юнит-тесты и тесты конвейера
pnpm --filter @ait/extension build     # → apps/extension/dist (Chrome) и dist-firefox
pnpm --filter @ait/mobile dev          # веб-приложение для телефона на http://localhost:5173

cd engine
python -m venv .venv && .venv/bin/pip install -e ".[dev]"   # Windows: .venv\Scripts\pip
.venv/bin/python -m pytest -q
.venv/bin/python -m app                # запуск движка; --lan — для телефонов в сети
```

Загрузка расширения: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → `apps/extension/dist`.

End-to-end тесты (нужен Chrome for Testing или Chromium и дисплей):

```bash
CHROME_PATH=/path/to/chrome xvfb-run -a node e2e/extension.e2e.mjs
MODE=engine CHROME_PATH=/path/to/chrome xvfb-run -a node e2e/extension.e2e.mjs
CHROME_PATH=/path/to/chrome node e2e/mobile.e2e.mjs
```

## Локальные модели под видеокарту

В настройках расширения (блок «Локальные модели») видеокарта определяется автоматически, рекомендуемая модель скачивается одной кнопкой, установленные модели можно проверить, переключить и удалить. Кнопка «Проверить модель» отправляет модели картинку с японским текстом и показывает, что она прочитала и за сколько секунд.

| Видеопамять | Модель (Ollama) | Размер | ~сек/стр. |
| --- | --- | --- | --- |
| 2 ГБ | `qwen3.5:0.8b` | 1,3 ГБ | 20–40 |
| 4 ГБ | `qwen3.5:2b-q4_K_M` | 1,9 ГБ | 20–40 |
| 6 ГБ | `qwen3.5:4b-q4_K_M` | 3,3 ГБ | 15–30 |
| 8 ГБ | `qwen3.5:4b-q8_0` | 5,2 ГБ | 15–25 |
| 12 ГБ (RTX 5070) | `qwen3.5:9b-q4_K_M` | 6,6 ГБ | 10–20 |
| 16+ ГБ | `qwen3.5:9b-q8_0` | 10 ГБ | 10–20 |

С Ollama расширение говорит через её родной API: режим размышлений выключен, окно контекста 16k — иначе Qwen3.5 «думает» минутами над каждой страницей.

Список рекомендуемых моделей и настройки для каждого семейства моделей (режим размышлений, окно контекста, размер картинки, формат координат) лежат в [`models.json`](models.json). Программа раз в день берёт свежий список из репозитория; если сети нет, работает встроенный. Когда для вашей видеокарты появляется модель лучше, в «Локальных моделях» появляется кнопка «Скачать и проверить»: новая модель скачивается и проверяется, и программа переключается на неё только после успешной проверки. Потом она предлагает удалить старую.

## Язык интерфейса

Настройки → «Язык интерфейса»: Как в системе (по умолчанию), Русский, English, Українська, Español, Português, Deutsch, Français, 日本語, 한국어, 中文. «Как в системе» — язык браузера; Chrome на Windows по умолчанию берёт его из Windows. Если такого языка нет, интерфейс будет на английском. Новые пользователи по умолчанию переводят мангу на язык системы. Переводы интерфейса лежат в `packages/core/src/i18n/locales`; как добавить язык — `packages/core/src/i18n/TRANSLATING.md`.

## Качество перевода

- Перевод отдельным шагом (по умолчанию, кроме быстрого режима): модель сначала читает страницу, отмечая, кто говорит и какого он пола, а затем переводит всю страницу как одну сцену. Так точнее смысл и окончания слов («я пришёл / я пришла»).
- Проверка перевода исправляет и «мелкие» ошибки в окончаниях и согласовании.
- Облачка любой формы — с шипами, «облако мыслей», волнистые рамки: стирается весь текст внутри, перевод вписывается по настоящему контуру. Если модель вообще пропустила облачко, программа находит оставшиеся буквы и дочитывает этот кусок.
- Оформление: заглавные, жирность, цвет, обводка букв (белые буквы с чёрным контуром) и выравнивание (подписи «по левому краю») переносятся с оригинала.

После сохранения ключа список моделей загружается сам, а кнопка «Использовать для перевода» сразу делает сервис основным (и разрешает отправку картинок в облако). ## Сверка с другими переводчиками

Настройки → «Сверка с другими переводчиками». Перевод страницы сравнивается с DeepL, Google Translate, Yandex Translate, LibreTranslate (можно свой, на этом компьютере) или с другой моделью из списка. Переводчиков можно включить сколько угодно; ключи хранятся в зашифрованном хранилище. «Кто сравнивает»: модель, которая переводит, любая другая модель или никто (тогда строка помечается, если перевод почти не совпадает ни с одним другим). «Если найдена ошибка»: только показать или исправить сразу (старый вариант можно вернуть). В редакторе у блока видны варианты других переводчиков с кнопкой «Взять», «⚖ Сверить страницу» и «Обратный перевод». В локальном режиме приватности облачные переводчики не спрашиваются.

## Вебтуны, порезанные на куски

Многие сайты режут длинную ленту вебтуна на картинки, часто прямо посреди бабла. Соседние картинки одной колонки теперь переводятся вместе: они склеиваются только там, где через стык что-то нарисовано (бабл, разрезанный сайтом), до 8000 px. Модель видит бабл целиком, а результат разрезается обратно по исходным картинкам для оверлеев, PDF и кэша. Выключается в Настройки → «Склеивать соседние картинки ленты». В редакторе кнопка «Глава целиком» показывает все переведённые картинки главы одной лентой с отметками границ. Бабл на стыке правится как один, и при сохранении результат разрезается обратно.

## Удобство

- Уже переведённые картинки показываются сразу, как только страница открывается снова (без модели). Отключается в настройках.
- «Только баблы» и «Только <язык>» — галочки в окне расширения. Первая оставляет звуки и надписи на фоне как в оригинале, вторая — текст на других языках. Ставятся и снимаются одним щелчком.
- «Очистить всё» убирает все переводы со страницы.
- «Сохранять каждую переведённую картинку» сохраняет её в «Загрузки/AI Translate/<сайт>/<глава>/». По умолчанию выключено.
- Наборы настроек (модель, качество, проверка) можно сохранить и переключать одним выбором в настройках и в окне расширения.
- Кнопка «ⓘ» на картинке показывает время, токены, стоимость и модель.
- Страница приветствия появляется после установки.
- «Сообщить о проблеме» (Настройки, внизу) собирает файл с версией, настройками и ошибками. Ключи API в него не попадают.

## Редактор

- Ctrl+колесо приближает к курсору, средняя кнопка мыши двигает страницу, Shift+колесо или [ ] меняют размер кисти.
- Ctrl/Shift+щелчок выделяет несколько блоков, Ctrl+A — все. Стиль меняется у всех выбранных; есть «Копировать стиль», «Вставить стиль» и «Стиль ко всем DIALOGUE».
- Кнопки ⧉ копируют оригинал или перевод. Тексты страницы можно сохранить в .txt или JSON, поправить где угодно и загрузить обратно.
- Шрифты: поиск, предпросмотр, свои шрифты (TTF/OTF/WOFF2) запоминаются.
- Эффекты текста: свечение, градиент, межбуквенный интервал, тень, прозрачность.
- PSD для Photoshop: оригинал, очищенная картинка и каждый текст отдельным слоем.
- В проектах страницы можно переставлять и удалять, а остальные страницы главы видны рядом с редактором (снизу или справа).
- «Стирать оригинал с запасом» (0–12 px) задаёт, насколько стирать вокруг букв.
- Фон под текстом на рисунке дорисовывает нейросеть LaMa: в локальном движке или прямо в браузере (модель ~200 МБ скачивается один раз кнопкой в настройках, работает на видеокарте через WebGPU).
- Правая кнопка мыши, зажатая с кистью или ластиком, меняет их размер; пипетка (I или Alt+щелчок) берёт цвет с картинки; страницы проектов можно обрезать (⛶).
- Наклонные буквы оригинала остаются наклонными в переводе.
- Настройки (модели, профили, глоссарий, наборы) сохраняются в файл и загружаются на другом компьютере — без ключей API.
- После перевода страницы и главы видно время модели, токены и стоимость.

## Глава целиком в файл

Окно расширения → «Перевести и скачать» (PDF, CBZ, EPUB или ZIP): расширение переводит все картинки страницы, включая ещё не загруженные, показывает прогресс «готово 12 из 40» и само скачивает файл с названием главы. В файл попадает только лента самой главы (реклама, превью других эпизодов и комментарии отбрасываются); расширение само прокручивает главу до конца, чтобы подгрузились все страницы, и возвращает прокрутку назад. Страницы никогда не режутся посреди бабла. Длинные полосы вебтунов режутся на страницы по белым промежуткам между кадрами, чтобы не резать баблы. Длину страницы можно выбрать рядом с форматом или в настройках: «Обычные» (как страница книги), «Длинные» (примерно втрое длиннее) или «Без нарезки» (лента целиком, до ~12 000 px на страницу — больше PDF не позволяет). Не переведённые картинки пропускаются, и об этом пишется.

Форматы в студии и приложении для телефона: на вход — PNG, JPG, WEBP, AVIF, GIF, BMP, PDF, ZIP, CBZ, EPUB (в порядке чтения книги); на выход — PDF, CBZ (с ComicInfo.xml), EPUB (фиксированная вёрстка), ZIP с PNG/JPG/WEBP. CBR/RAR и TIFF браузер открыть не может — программа объясняет, как их переконвертировать.

## Проверка перевода

После перевода страница проверяется ещё раз (один короткий запрос к той же модели). Языковая проверка — грамматика, орфография, пунктуация, термины, оформление; смысловая — смысл, контекст, намерение, эмоции, речь персонажей. Часть проверок делается без модели: непереведённый текст, потерянные «?» и «!», числа, глоссарий, имена из контекста. Режимы (Настройки → «Как переводить»): исправлять ошибки автоматически (по умолчанию), только показывать замечания, выключено. На картинке с замечаниями появляется кнопка 🔍, отчёт и кнопка «Вернуть» — в редакторе.

## Вёрстка как в оригинале

- Текст стирается целиком, даже если модель обвела его неточно; баблы, обрезанные краем картинки, распознаются; если бабл выходит за рамку кадра на белое поле, стирается весь его текст, а белая подложка не залезает на рисунок; текст перевода не уходит за край картинки; если модель пропустила реплику или строку, оставшиеся на бабле буквы находятся после очистки, и этот кусок читается и переводится отдельно; размер шрифта перевода берётся по высоте букв оригинала; блоки одного бабла склеиваются, чтобы переводы не накладывались.
- Звуковые эффекты стираются по буквам, без размазывания рисунка вокруг, и перевод встаёт на их место.
- Шрифт реплик — AIT Lettering (Balsamiq Sans, OFL, с кириллицей); заглавные, жирность и цвет берутся из оригинала.
- «Перевести страницу» берёт и ещё не загруженные картинки (ленивую загрузку, как на Webtoons), и продолжает переводить новые при прокрутке.

## Если не хватает программ

Перед локальным переводом расширение проверяет, запущены ли Ollama (или LM Studio, или движок) и скачана ли модель. Если чего-то нет, на картинке появляется кнопка «Установить и запустить», а помощник в настройках предлагает скачать Ollama, ждёт её запуска, скачивает модель под видеокарту, проверяет её и сам продолжает перевод страницы.

## Если перевод останавливается или идёт медленно

- Браузер иногда закрывает фоновую часть расширения посреди главы. Картинки, которые при этом «потерялись», отправляются заново сами (до двух раз), глава доводится до конца без нажатий.
- Сторож: если по картинке нет ответа 12 минут (локальная модель) или 5 минут (облако), она пропускается с понятной причиной, а очередь идёт дальше.
- Пока в очереди есть страницы, модель держится в видеопамяти, чтобы не загружаться заново перед каждой.
- Если модель не помещается в видеокарту целиком (часть в обычной памяти — главная причина резкого замедления), окно расширения предупреждает и советует модель поменьше.
- Окно контекста Ollama: 8k токенов, 16k — только при 16 ГБ видеопамяти и больше.
- В окне расширения видна средняя скорость (секунд на страницу) и предупреждение, если она хуже обычной для выбранной модели; после «Проверить модель» — скорость в токенах в секунду.
- Быстрый режим (Настройки → Локальные модели): картинка для модели 1280 px вместо 1568 (на треть меньше пикселей) и проверка перевода без отдельного запроса к модели.
- «Ускорить Ollama»: `setx OLLAMA_FLASH_ATTENTION 1`, `setx OLLAMA_KV_CACHE_TYPE q8_0` (сжатый кэш работает только вместе с flash attention), `setx OLLAMA_NUM_PARALLEL 1`, `setx OLLAMA_MAX_LOADED_MODELS 1`.
- Если видеопамяти не хватило, программа сама пробует ещё три раза, каждый раз легче: сначала выгружает другие модели, затем уменьшает контекст до 8k, затем до 4k и уменьшает картинку. Если не помогло, на картинке появляется кнопка «Освободить и повторить».

## Выключатель и видеопамять

Переключатель «Вкл/Выкл» в окне расширения останавливает все переводы, убирает кнопки с картинок и выгружает модель из видеопамяти (на значке появляется OFF). В окне видно, сколько памяти сейчас занимает модель, и есть кнопка «Освободить». В настройках «Локальные модели» можно выбрать, сколько держать модель в памяти после перевода: от «выгружать сразу» до часа (по умолчанию 5 минут).

## Обновление

«Настройки → Проверить обновления → Обновить сейчас». Расширение один раз попросит выбрать свою папку (ту, что указана в chrome://extensions), дальше скачивает новую версию с GitHub, записывает файлы и перезапускается само. Android скачивает новый APK, iPhone открывает страницу релиза.

## Приватность

Режим «Только локально» проверяется кодом: изображения и текст не уходят за пределы устройства или локальной сети, облачный провайдер просто не будет вызван. Гибридный режим отправляет наружу только распознанный текст. Ключи API хранятся на устройстве в зашифрованном виде (AES-GCM, неэкспортируемый ключ WebCrypto) и не попадают в настройки, экспорт или синхронизацию.

## Структура

```
apps/extension   расширение MV3 (Chrome, Edge, Brave, Opera) + сборка для Firefox
apps/mobile      веб-приложение для телефона + проекты Android и iOS (Capacitor)
packages/core    ядро: модели, перевод, очистка, вёрстка, конвейер
packages/studio  интерфейс студии и редактора
engine           локальный движок на Python
e2e              end-to-end тесты в настоящем браузере
site             сайт с тремя страницами установки
scripts          иконки и упаковка релизов
```

Лицензия кода — MIT. Веса моделей не входят в репозиторий и распространяются по своим лицензиям (`engine/models/README.md`).
